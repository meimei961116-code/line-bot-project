專題介紹

專案名稱

LINE 官方智慧對話助理（LINE Bot Powered by Google Gemini AI）

專案定位

新一代生成式 AI 企業/個人客服與智慧諮詢助理

核心技術棧

  • 後端框架：Python 3.12、Flask
  • API 整合：LINE Messaging API SDK v3
  • AI 大語言模型：Google Gemini 3.5 Flash 旗艦模型
  • 網路代理：Cloudflare Tunneling（安全隧道連接）

專案目標

打造具備以下特性的 24 小時無間斷 LINE 智慧對話系統：

  • ✓ 高邏輯思考能力與複雜推理
  • ✓ 上下文多輪對話記憶管理
  • ✓ 即時時空感知與動態回應
  • ✓ 企業級資安防護機制

專案摘要 (Executive Summary)

本專案以 Google Gemini AI 為核心，結合 LINE 官方推播與互動能力，目標建立一個可長期運作的智慧客服與諮詢平台。

設計重點包括：上下文記憶、多輪對話、即時時空感知與長期穩定運營。
